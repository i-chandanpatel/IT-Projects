CSS Gradients Playground

Linear Gradients linear-gradient()

Main properties to play with: direction / angle, color stops, and repeating-linear-gradient().

To right (default smooth blend)
background: linear-gradient(to right, #3b82f6, #ec4899);
To bottom
background: linear-gradient(to bottom, #22c55e, #0ea5e9);
45deg angle
background: linear-gradient(45deg, #f97316, #22c55e, #0ea5e9);
Color stops with positions
background: linear-gradient( to right, #ef4444 0%, #ef4444 30%, #eab308 30%, #eab308 70%, #22c55e 70%, #22c55e 100% );
Overlay style using transparency
background: linear-gradient( to bottom, rgba(15, 23, 42, 0.1), rgba(15, 23, 42, 0.9) ), url("image.jpg") center/cover no-repeat;
repeating-linear-gradient() stripes
background: repeating-linear-gradient( 45deg, #f97316 0px, #f97316 10px, #111827 10px, #111827 20px );

Radial Gradients radial-gradient()

Main properties: shape (circle / ellipse), size (closest-side, farthest-corner, etc.), position (at top left), and repeating-radial-gradient().

Default ellipse at center
background: radial-gradient(#22c55e, #0f172a);
Circle at center
background: radial-gradient(circle, #f97316, #0f172a);
Circle at top left
background: radial-gradient(circle at top left, #3b82f6, #0f172a);
closest-side (stops at nearest edge)
background: radial-gradient( circle closest-side, #22c55e, #0f172a );
farthest-corner (fills box fully)
background: radial-gradient( circle farthest-corner at 30% 30%, #eab308, #0f172a );
Multi-stop radial (glow effect)
background: radial-gradient( circle, rgba(56,189,248,0.9) 0%, rgba(56,189,248,0.4) 30%, rgba(15,23,42,1) 70% );
repeating-radial-gradient() rings
background: repeating-radial-gradient( circle at center, #22c55e 0, #22c55e 8px, #0f172a 8px, #0f172a 16px );

Conic Gradients conic-gradient()

Main properties: from angle, position (at x y), color stops, and repeating-conic-gradient(). Very useful for pie-chart, spinner type designs.

Basic conic (spectrum)
background: conic-gradient( from 0deg, #ef4444, #f97316, #eab308, #22c55e, #0ea5e9, #6366f1, #a855f7, #ec4899, #ef4444 );
Pie chart style sectors
background: conic-gradient( #22c55e 0deg 90deg, #3b82f6 90deg 210deg, #eab308 210deg 360deg );
Moved center (at top left)
background: conic-gradient( from 0deg at 10% 10%, #f97316, #22c55e, #0ea5e9, #f97316 );
Donut effect using mask
background: radial-gradient(circle at center, #020617 40%, transparent 41%), conic-gradient( #22c55e 0deg 120deg, #3b82f6 120deg 240deg, #f97316 240deg 360deg );
repeating-conic-gradient() wedges
background: repeating-conic-gradient( from 0deg, #f97316 0deg 10deg, #111827 10deg 20deg );

Quick Summary of Properties You Can Play With

linear-gradient(): angle | to direction, color stops with optional % or px positions, repeating-linear-gradient().

radial-gradient(): circle | ellipse, size (closest-side, closest-corner, farthest-side, farthest-corner), position (at x y), repeating-radial-gradient().

conic-gradient(): from <angle>, at x y to move the center, angle ranges for each color stop, repeating-conic-gradient().
