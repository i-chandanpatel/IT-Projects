Guide to CSS Units

In this article, we will see how to set CSS units in different ways and understand their behavior through examples.

% (Percentage)

The % unit is relative to a value set on the parent element. For font-size, it's relative to the parent's font size. For properties like width or height, it's relative to the parent's width or height.

Parent Element (font-size: 20px, width: 100%)
Child Element (font-size: 150%, width: 75%)

The font size here is 150% of 20px (30px). The width is 75% of the parent's width.

em

The em unit is relative to the font-size of the element itself. If the element doesn't have a font-size set, it inherits it from its parent. This can lead to a "compounding" effect when nested.

Note: 2em means 2 times the size of the current font context.

Parent (font-size: 16px)
Child 1 (font-size: 1.5em). Calculated size: 1.5 * 16px = 24px.
Child 2 (font-size: 1.5em). Calculated size: 1.5 * 24px = 36px. This shows compounding.

rem (Root em)

The rem unit is relative only to the browser's base font-size, which is set on the root element (<html>). The default is almost always 16px. This unit avoids the compounding issue of em.

Parent (font-size: 30px). This font-size is ignored by the `rem` unit below.
Child (font-size: 2rem). Calculated size: 2 * 16px (root) = 32px.

px (Pixels)

The px unit is an absolute, fixed-size unit. A pixel is a single dot on the screen. It is not scalable and is often used for elements that should remain a constant size, like borders.

Note: On a standard display, 96px = 1in.

This box has a fixed font-size of 18px and a fixed width of 300px. It will not change if you resize the browser or change the base font size.

vh (Viewport Height)

The vh unit is relative to 1% of the height of the viewport (the visible area of the browser window). 100vh is the full height of the viewport.

This box has a height of 40vh.
Try resizing the height of your browser window to see it change.

vw (Viewport Width)

The vw unit is relative to 1% of the width of the viewport. 100vw is the full width of the viewport.

This box has a width of 80vw. Try resizing the width of your browser window to see it change.

Notes & Best Practices

  • Absolute vs. Relative:
    • Absolute Units: px. They are fixed and do not change based on any other element or setting.
    • Relative Units: %, em, rem, vh, vw. They are flexible and scale with respect to another value.

  • When to Use What?
    • Use rem for font sizes, margins, and padding to create a scalable and accessible design. This is the modern standard for most sizing.
    • Use em when you want an element's size to be relative to its own font-size context (e.g., the padding on a button should scale with its text).
    • Use % for creating fluid layouts, like columns in a grid that should take up a percentage of their container's width.
    • Use px for things that must not scale, like borders (e.g., border: 1px solid black;) or when working with fixed-size design elements.
    • Use vh and vw for sizing elements relative to the browser window, which is perfect for full-screen hero sections or layout elements that should always be visible.
