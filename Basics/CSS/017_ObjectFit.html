object-fit: cover;
Image fills the element while maintaining aspect ratio. Parts may be cropped.
object-fit: fill;
Image stretches to fill the element. Aspect ratio is not preserved.
object-fit: contain;
Image is scaled to fit inside the box. Aspect ratio is preserved, may leave empty space.
object-fit: scale-down;
Uses either none or contain, whichever is smaller. Aspect ratio preserved.
background-image with:
background-repeat: no-repeat;
background-clip: content-box;
Image is shown only within the content area, not padding or border.
No object-fit applied;
Image displayed using default browser behavior. Fills width unless constrained.
